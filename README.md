# 个人情报库

一个以本地文件为资料来源的个人报告整理工具。完整原文、简明卡片和来源分开保存，通过单文件 HTML 阅读、筛选和搜索。

本仓库是去除个人资料后的源码副本，不包含任何实际报告、复盘、会话记录、浏览器资料或账号配置。初次使用会创建空资料库。

## 功能

- 六类报告栏目，按建议与进度筛选，搜索标题、摘要和完整原文。
- 保留 UTF-8 原文，用 SHA-256 指纹检查意外改动。
- 支持归档、回收站与恢复；管理操作保存为本地事件文件。
- 保留手动收录队列、事务提交、去重、检查断点和浏览器扩展源码。
- 生成的首页可以离线阅读，不依赖网页服务器。

## 开始使用空资料库

准备 Python 3.11 或更新版本，完整下载本仓库，在项目目录运行：

```powershell
python scripts/init_library.py
python scripts/build.py --check
```

双击生成的 `个人情报库.html`。初始化只创建空资料和随机项目编号，不安装浏览器扩展、不注册系统任务、不启动收录。已有资料或首页时会拒绝覆盖。

更新本地资料后，运行以下命令验证原文并重新生成首页：

```powershell
python scripts/build.py
```

阅读和搜索只需浏览器。页面上的归档、回收站及请求文件写入，需要支持文件夹授权的浏览器并由使用者选择本项目文件夹。

## 手动收录与后台模块

公开代码中的来源会话、部署标识和历史诊断标识均为示例。**后台收录和扩展需要使用者自行配置，下载源码后不能直接抓取 ChatGPT 报告。** 空资料库默认 `manual_only` 且 `enabled=false`。

`scripts/intake_alias.py`、`browser-extension/worker.js`、扩展匹配规则等处的示例来源必须保持一致。原部署的扩展公钥已移除；使用者需要提供自己的扩展公钥和对应扩展 ID，并同步原生接收器及代码中的身份校验。浏览器登录和本机程序位置也需要对应配置；摘要模块通过 `CODEX_CLI` 环境变量或 PATH 查找程序。Windows 后台模块使用本机锁与隐藏任务，未提供跨平台一键安装。安装与补收模块应在核查配置后使用，历史现场实验脚本未包含在公开副本中。

首页按钮只保存手动请求。后台未配置时，保存请求不代表报告已收录；完成状态应以真实原文、提交结果和检查断点为准。当前公开副本不附带作者的运行环境或真实运行证据。

## 资料与代码分开管理

以下内容由本地使用产生，不应提交到公开仓库：

- `data/`：报告目录、完整原文、周复盘、管理记录和本机配置。
- `.intake/`：采集原始数据、请求回执、浏览器资料与临时工作文件。
- `evidence/`：本机运行日志、截图与验证记录。
- `个人情报库.html`：生成页会嵌入完整报告，不能作为无数据的源码文件上传。
- 密钥、令牌、环境变量文件、数据库和浏览器用户目录。

仓库的忽略规则用于降低误传概率。每次提交仍应查看暂存文件清单，避免用强制添加绕过规则。`examples/catalog.example.json` 是空结构模板，不是用户资料。

## 测试

公开测试使用内存数据或临时合成文件，不需要个人资料；依赖私人资料、现场证据或本机可执行文件的测试未包含。前端测试需要 Node.js；后台的部分测试依赖 Windows：

```powershell
python -B -m unittest discover -s tests -p "test_*.py"
$testFiles = Get-ChildItem tests -Filter '*.mjs' | ForEach-Object FullName
node --test $testFiles
```

测试通过只说明对应代码场景通过，不代表其他机器的浏览器登录、扩展安装或真实采集已验收。

## 目录

| 目录 | 内容 |
| --- | --- |
| `ui/` | 首页模板、样式和交互代码 |
| `scripts/` | 构建、校验、收录与管理模块 |
| `browser-extension/` | 浏览器读取扩展源码 |
| `tests/` | 可公开的合成测试 |
| `examples/` | 无资料的结构模板 |

本仓库暂未附加开源许可证；公开可见不等于授予额外使用许可。
