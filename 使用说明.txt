个人情报库：公开源码副本

1. 安装 Python 3.11 或更新版本，完整下载并解压源码。
2. 在项目目录执行 python scripts/init_library.py，创建空资料库。
3. 双击生成的“个人情报库.html”，即可阅读和搜索本地资料。
4. 更新本地资料后，执行 python scripts/build.py 重新生成首页。

首次初始化不会导入报告，也不会安装扩展、注册系统任务或启动后台收录。
已有资料或首页时，初始化会拒绝覆盖，请勿删除旧资料来强行初始化。

公开副本中的后台和扩展使用示例来源及部署标识，需要另行配置。
在配置完成前，首页保存手动请求不等于已经执行或完成收录。
具体结构、使用条件和测试说明见 README.md。

data、.intake、evidence 和生成的“个人情报库.html”可能包含私人资料，不能上传公开仓库。
资料中出现的价格、结论和来源不等于已经核验；完整原文请保持原样保存。
